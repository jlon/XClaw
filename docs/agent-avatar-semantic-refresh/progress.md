# 智能体头像语义化重构进度

## 当前状态

- 已确认用户目标不是“换一种随机头像”，而是“头像符合智能体定位”
- 已核对 `openclaw-control-center` 源码，确认其 staff 头像是内置像素动物 + `agentId` 关键词映射，不适合直接照搬
- 已确认 XClaw 当前头像系统仍是无语义 identicon
- 已完成方案收敛：
  - 不走远程 API
  - 不走像素动物复刻
  - 采用 DiceBear 本地库
  - 采用 `bottts-neutral`
  - 采用本地 / 市场统一语义映射层
- 当前处于“设计已锁，等待进入实现计划”阶段

## 已完成内容

### 调研层

- 已定位 XClaw 当前头像实现和调用点
- 已定位市场模板的头像元数据现状
- 已定位本地智能体可用的 `SOUL.md / IDENTITY.md` 数据入口
- 已核对 `openclaw-control-center` 的真实实现边界
- 已确认 DiceBear 官方 JS Library 和 `bottts-neutral` 可满足离线、本地、稳定生成需求

### 设计层

- 已确定视觉方向为“低噪声、中性机械感、桌面工作台风格”
- 已确定语义判定采用规则引擎，不使用 AI
- 已确定本地和市场都输出统一 `AgentAvatarProfile`
- 已确定本地智能体需要后端富化，市场模板需要 catalogue 富化
- 已确定失败时保留旧 identicon fallback
