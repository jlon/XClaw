# XClaw 下载同步问题记录

## 当前已知约束

### 1. GitHub `latest` 接口不适用于当前仓库

当前仓库公开 API 的 `/releases/latest` 返回 `404`，原因是当前最新发布为 `prerelease`。
因此同步脚本必须改用 `/releases?per_page=1` 列表接口。

### 2. Windows 资产存在多种命名

当前公开 release 同时存在：

- `...-win.exe`
- `...-win-x64.exe`
- `...-win-arm64.exe`

官网只保留一个 Windows 按钮，因此同步脚本采用优先级选择，而不是把三个都暴露到首页。

### 3. 下载目录不能放在官网发布目录内

官网静态页面通过发布目录切换更新，如果下载文件放在同一发布目录，后续网站重发时容易被覆盖。
因此下载文件必须放到独立目录，并通过 Nginx `alias` 对外暴露。

### 4. 首页不能硬编码最新版本号

如果官网把下载链接直接写死到某个具体 tag，后续每次发版都要重新发布官网静态文件。
因此首页按钮只保留平台标识，真实下载地址通过 `/downloads/latest.json` 在运行时注入。
