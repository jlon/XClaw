## 已确认结论

- 聊天列表当前最主要的问题是网页感，不是功能缺失
- `QClaw` 值得学的是轻列表、弱 hover、去每行时间、弱动作暴露，以及默认单行 source list
- `XClaw` 自己更值得保留的是 inline 搜索和“仅在必要时才补多 Agent 区分”
- 这轮确认了“inline 搜索”也不意味着必须保留常驻 input；更像桌面的做法是先 trigger，再按需进入输入态
