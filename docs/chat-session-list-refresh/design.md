# 聊天列表去网页感改造设计

## 背景

当前聊天左侧会话列表已经能用，但视觉语言仍然偏网页：

- 搜索框仍像独立表单组件，表单感重
- 会话项还是“组件块”而不是 source list 行
- 顶部局部标题、副标题和头像会持续把列表拉回内容栏思维
- 选中态更像一张网页卡片，而不是桌面应用中的当前行
- 当前身份头像使用高饱和渐变圆球，AI 产品味过重

这轮目标不是重做聊天能力，而是在既有 `global-theme-refresh` 基础上，把会话列表收成更像桌面应用的“工具化会话轨”。

## 参考与证据

### QClaw 已确认值得借鉴的点

基于本机解包源码与样式证据：

- 侧栏宽度接近 `250px`，主列表是 source list，而不是内容卡片区
- 顶部 header 只有紧凑操作区，不额外抬一个本地 pane 标题
- 左侧主列表是轻量分组文本列表，不是信息密集卡片列表
- 主列表不显示每行时间，时间主要用于分组与搜索结果
- hover / 选中态都很轻，更多动作默认隐藏
- 分组更粗：`今天 / 本周 / 本月 / 更早`
- 搜索入口更克制，整体更像轻筛选 trigger，而不是大输入框
- 默认行只有一行文字，更多区分信息只在必要时才补出来

### 不直接照抄的点

- 不把搜索改成弹层，XClaw 当前侧栏内搜索更直接
- 不盲目抄 QClaw 的像素皮和图标细节
- 不为了模仿而去掉 XClaw 真正有价值的多 Agent 可辨识度
- 不照抄 QClaw 的像素皮、颜色和固定宽度

## 目标

- 将聊天列表收成桌面工具轨，而不是网页内容栏
- 保留多 Agent 会话辨识度，但去掉 AI 化头像
- 降低列表项信息密度，让主次关系更清楚
- 保持与 `global-theme-refresh` 的浅色/深色主题一致
- 不破坏现有搜索、切换、新建、删除等行为

## 非目标

- 不重做聊天 store
- 不把搜索改成独立弹窗
- 不引入未读计数、复杂 hover 动画或新会话类型体系
- 不重做聊天正文与输入区结构

## 设计结论

### 1. 侧栏结构

- 聊天 route 下的 rail 与会话列表视为同一套导航壳层，不再看起来像两块独立网页栏
- 不再保留本地 pane 标题，只保留紧凑的新建操作区
- 保留侧栏内搜索能力，但默认先以更接近 trigger 的轻筛选器呈现，进入搜索时再展开输入态
- 会话区继续使用分组列表
- rail 右侧的会话列表宽度收紧到接近 `QClaw` 的一档，优先采用 `248px` 左右

### 2. 分组策略

从当前：

- 今天
- 昨天
- 一周内
- 两周内
- 一个月内
- 一个月之前

收敛为：

- 今天
- 本周
- 本月
- 更早

原因：

- 更接近 QClaw 的工具化会话轨
- 侧栏导航不需要过细时间桶
- 主列表去掉每行时间后，分组承担主要时间定位职责

### 3. 会话项

- 默认每项只保留一行标题文本
- 当多个会话标签重复时，才以内联弱化后缀补 `Agent` 区分
- 去掉当前每行右侧时间
- 选中态从“网页卡片”改成 source list 当前行
- hover 只做轻 surface 浮起
- 删除按钮默认隐藏，仅在 hover / focus 时出现

### 4. 身份章

- 聊天列表默认不再展示身份章
- 多 Agent 辨识度优先通过会话标签和必要时的内联后缀承担
- 共享身份章继续保留给聊天正文与其他真实需要身份标识的位置

### 5. 搜索区

- 保留侧栏内搜索能力，但不再常驻展示成厚输入框
- 默认先展示为轻筛选 trigger
- 点击后在原位展开输入态，避免额外弹层和一次跳转
- 图标、占位文字和边框都进一步弱化
- 不增加额外按钮或高级筛选

### 6. 明确保留 XClaw 更好的部分

- 保留侧栏内搜索，不改成独立弹层
- 保留多 Agent 的会话辨识度，但只在标签重复时再补最小区分信息
- 保留 rail 与主列表并存的应用导航能力，不把整个聊天导航退化成单栏

## 风险

- 去掉每行时间后，回看最近会话的精确时间信息会下降
- 默认单行文本后，多 Agent 区分是否仍足够需要真实使用验证
- 分组口径从 rolling window 收成自然时间桶后，需要同步调整测试与文案
- 本轮“本周”按本地周一作为起点，后续如果产品口径变更，需要单独再改

## 验收标准

- 列表首屏不再像网页卡片流
- 渐变头像全部退出聊天列表
- 本地 pane 标题退出聊天列表
- 列表默认回到单行 source list
- 主列表不再展示每行时间
- 搜索、新建、切换、删除行为保持可用
- 深浅主题与 mac / Windows 轻度适配保持一致
