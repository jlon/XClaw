# 聊天性能与流畅度优化实施计划

## 第一阶段

### 1. 滚动初始化减重

- 简化 `use-stick-to-bottom-instant`
- 去掉 `visibility: hidden`
- 收紧首屏与切换会话时的滚底策略

### 2. 消息行结构重构

- 主层只保留头像与正文
- meta 与复制独立为轻次级行
- thinking / tool / 图片 / 文件统一放到正文后

### 3. 宽度与对齐收敛

- 统一聊天阅读列
- 用户与助手消息都对齐到同一套列系统
- 复制与时间不再脱离消息列

### 4. 定向验证

- 补消息宽度与滚动行为测试
- 在真实 `dev` 环境验证用户反馈截图对应问题

## 第二阶段候选

仅在第一阶段完成后再决定是否需要：

1. 长会话轻量化窗口化
2. 图片与代码块的懒加载
3. 搜索跳转和高亮反馈
