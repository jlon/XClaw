# XClaw 官网测试

## 目标

本文件用于记录官网页面在实现阶段和交付前的验证口径。

本轮官网不是桌面应用功能页，而是本地可预览的单页站点，因此验证重点不是业务状态流，而是：

- 页面是否能稳定打开
- 视觉和结构是否符合设计
- 图片与素材是否全部来自本地仓库
- 桌面端和移动端是否都可正常浏览

## 计划验证项

### 1. 本地预览

- 官网入口可直接启动
- 本地访问地址正常打开
- 刷新页面后不白屏

### 2. 页面结构

- 首屏、能力区、场景区、下载区、FAQ 区顺序正确
- 导航锚点可跳转到正确区块
- 结尾 CTA 不丢失

### 3. 文案术语

- 主标题、副标题、区块标题符合设计文档
- 不混入 `runtime / gateway / plugin / orchestration` 等内部词
- 不把页面写成开发者工具说明书

### 4. 素材加载

- Logo 正常显示
- README 截图正常显示
- 渠道和模型图标不丢失
- 不依赖外链图片

### 5. 响应式

- 常规桌面宽度下布局稳定
- 窄屏下模块正常折叠
- 移动端文本不溢出、按钮可点击

### 6. 交互

- 导航点击可跳锚点
- 截图区域切换正常
- 下载按钮样式与可点击态正常

## 计划执行命令

根据最终落地方式，至少补齐以下验证：

- 官网本地启动命令
- 静态构建命令
- 类型检查命令
- 需要时的 lint 命令
