# Windows 安装器日志与取消交互问题清单

## 已确认问题

1. Windows 安装器默认只显示进度条，不显示实时日志。
2. 安装阶段取消按钮不可用，用户无法主动中止。
3. 之前实现的日志/取消位于应用内 Setup，不覆盖 NSIS 安装器层。
4. 通过定时器轮询原生安装页控件并覆盖文案的方案存在运行时风险，已在新包中触发安装器异常，不能继续沿用。

## 已知边界

1. NSIS 取消安装后不保证自动回滚已解压文件。
2. electron-builder 默认模板会在安装段执行 `SetDetailsPrint none`，需要在我们的脚本里显式恢复。
3. 如切到 `nsis.script` 自定义根脚本，electron-builder 不再自动签名 uninstaller，这个代价高于当前需求收益。
4. 安装器稳定性优先于安装页美化，后续若要再做视觉定制，必须基于可验证的 NSIS 官方机制，而不是轮询窗口句柄。

## 待观察

1. 日志默认展开后，在较小分辨率下是否需要调整安装器窗口高度。
2. 取消后留下的安装目录是否需要在后续版本补充清理提示。
