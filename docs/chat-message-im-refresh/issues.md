# 聊天消息区桌面 IM 质感对齐问题记录

## 当前已知风险

1. `ChatMessage.tsx` 同时承载正文、图片、附件、工具链、思考区，改动面集中，需要避免把现有富内容渲染打坏。
2. 现有 `chat-theme-shell.test.ts` 含大量源码级断言，消息区参数调整后需要同步维护。
3. 用户消息与助手消息的元信息条如果改成浮动，需要兼顾 hover 与键盘 focus 可达性。
4. feedback panel 当前只做本地交互态，未接入真实反馈提交链路。

## 后续观察点

1. 长文本用户消息在窄窗口下是否仍保持自然换行。
2. 附件卡和图片卡在用户/助手两侧是否还会显得拥挤。
3. Windows Overlay Scrollbar 与 mac 原生滚动条在真实 Electron 窗口里是否仍保持统一观感。
4. typing / processing bubble 与流式文本尾部三点在长会话里是否还需要进一步合并节奏。
5. 工具阶段 assistant 快照目前会主动剥离正文文本，只保留 `thinking / tool_use` 过程块；后续如果网关事件语义变化，需要重新核对这条假设是否仍成立。
