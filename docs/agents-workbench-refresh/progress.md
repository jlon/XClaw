## 当前判断

### 当前判断

这轮 review 后，文档不再继续使用 `92%-96%` 这类没有约束力的进度估算。  
当前更准确的表述是：

- 设计红线：已锁死
- 本地模式的自适应卡片浏览区：主结构已落地，剩余是卡片密度与默认窗口下的观感收口
- 市场浏览与安装布局：主结构已闭环，剩余是桌面商店陈列感收口
- 右侧 detail pane：已进入收尾阶段
- 剩余主要是最终手工体验复核与少量层级精修
- 创建入口文案已收成桌面工具栏语法：主按钮使用短动词，分流语义留给下拉菜单，弹窗标题保留完整名词
- `概览` 已移除没有独立价值的“核心摘要”外壳，事实卡直接成为第一层信息，减少后台感与重复层级
- `概览` 中重复的人格文件/工作区事实卡已删除，默认只保留真正需要在概览承接的频道归属
- `概览` 页签已退役；本地智能体 detail 现在只保留两个真实工作面：`人格文件` 与 `绑定与运行`
- `绑定与运行` 已改成“频道账号主任务面 + 运行事实次级摘要”，不再把运行状态和运行时目录抬成与频道管理同级的后台 inspector
- `人格文件` 已收口成“内置文件清单 + 弹窗编辑”，默认不再暴露创建、上传、重命名、删除这套文件管理器分支
- 已给“编辑智能体”补上真实模型覆盖能力：
  - 设置弹窗现在支持搜索可用模型
  - 支持回退为 `OpenClaw` 默认模型
  - 保存会持久化到 `openclaw.json`
  - 只有模型变更才触发后台异步 runtime restart
  - 名称单独修改不会触发不必要的 runtime 重启
