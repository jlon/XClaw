# 全局壁纸问题记录

## 首版接受的取舍

- 首版不做 setup 页壁纸
- 首版不做多图轮播
- 首版不做铺放模式、模糊强度、遮罩颜色自定义

## 已知风险

- 某些过亮或过花的壁纸可能削弱局部文本对比度
- 某些页面内部如果继续引入自定义大面积实底，仍可能削弱统一壳层观感
- Studio、模型页、设置页虽然已经共享壳层材质，但不同内容密度下仍需要继续做真实壁纸抽样检查
- 聊天页虽然已增加独立阅读底板，但极暖色或极高对比壁纸下仍需继续检查长文本、代码块、附件区的局部层级是否足够干净
- 聊天页左上角虽然已把品牌从 titlebar 撤回，但仍需继续观察超窄侧栏宽度或极端字体缩放下的拥挤风险
- 首版只允许读取 XClaw 托管到 `userData/wallpaper/` 下的壁纸文件，避免 settings 被外部修改后读取任意本地路径

## 待确认项

- 首版是否需要图片大小上限与导入前压缩
- 是否需要支持清除后自动删旧文件夹中的历史残留
- 聊天页是否还需要针对代码块、工具状态 rail 单独增加更稳的低饱和 token，而不是继续跟随普通 secondary block

## 后续可扩展项

- 模糊与遮罩强度
- 铺放模式
- 多图轮播
- 每个 workspace 或每个页面独立壁纸
- 针对极亮壁纸的局部对比保护策略
- 聊天页阅读层的局部对比保护与智能遮罩
