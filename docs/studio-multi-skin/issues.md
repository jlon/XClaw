# 工作室多皮肤切换问题清单

## 当前已确认问题

- `Star-Office-UI` 并没有现成打包好的多套完整办公室皮肤，现有能力更接近“一套主场景 + 资产替换机制”
- 如果把 `join / invite / 桌宠` 一起纳入，会把“换皮”需求扩大成多页面与多窗口集成
- 如果皮肤允许修改布局骨架，会直接破坏角色路径、遮挡和点击区域

## 设计阶段待确认项

- 预置多少套首发皮肤最合理
- 哪些现有资源适合纳入“关键大件”映射
- 哪些资源必须固定，不能进入皮肤包

## 实现阶段重点风险

- 皮肤切换时的刷新成本是否会影响工作室切换流畅度
- 资源缺失时的回退链路是否足够稳
- 右上角“换皮”入口是否会与现有工作室 chrome 冲突
