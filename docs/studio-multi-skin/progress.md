## 已确认结论

- 只做办公室主场景多皮肤切换
- 不纳入 `join / invite / 桌宠`
- 每次进入工作室自动随机一套皮肤
- 工作室右上角保留轻量手动换皮入口
- 皮肤仅是固定资产映射，不是布局分支
- 每次离开工作室后当前实例皮肤锁失效，下次重新随机
- 首发三套皮肤均可参与随机与手动切换
