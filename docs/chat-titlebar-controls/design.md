# 聊天侧栏控制

## 目标

在聊天界面补齐并对齐 QClaw 的两项高频入口，并把工作台的侧栏收缩入口统一到同一套顶栏控件：

- 标题栏左侧聊天带切换会话侧栏显示/隐藏
- 标题栏左侧聊天带直接新建会话
- 工作台页标题栏左带切换全局 Sidebar 显示/隐藏

这组入口需要和搜索区分层：搜索留在会话侧栏内部，动作按钮留在标题栏顶带。

## 设计约束

- 复用现有 `chatFocusMode`，不新造布局状态机
- 复用现有 `sidebarCollapsed`，不再保留 Sidebar 内嵌的第二套收缩按钮
- 复用现有 `/new` 与多 Agent 选择逻辑，不退化成功能更弱的快捷按钮
- mac / win 共用同一套行为，只保留现有标题栏平台差异
- 图标使用 QClaw 的真实 SVG 路径，不再用近似的 Lucide 图标替代
- 标题栏按钮采用裸 icon action，不再套通用圆形 ghost button
- 侧栏展开时按钮挂在 `250px` 聊天带右侧；侧栏收起时按钮自动左对齐到交通灯右侧的紧邻区域
- Windows 不复用 mac 的交通灯安全区偏移；工作台收起态保持与 `w-11` rail 对齐，聊天收起态保持左缘起点对齐

## 实现要点

### 1. 标题栏左带动作区

在 `TitleBar` 左侧聊天带放置两个动作按钮：

- 会话侧栏切换
  - 图标使用 QClaw 同款面板图形
  - 点击后直接切换 `chatFocusMode`
- 新建会话
  - 图标使用 QClaw 同款对话加号图形
  - 单 Agent 时直接进入 `/new`
  - 多 Agent 时弹出选择菜单，再进入对应 `/new/:agentId`

在非聊天页：

- `TitleBar` 左侧改为挂载全局 Sidebar 收缩按钮
- 侧栏内部不再保留重复入口
- 展开时按钮贴近全局 Sidebar 右缘
- 收起时按钮随 rail 宽度一起收拢

### 2. 左右状态对齐策略

- 侧栏展开时：
  - 左侧预留 `250px` 会话带
  - 两个按钮右对齐到这条带的末端
- 侧栏收起时：
  - 取消固定带宽
  - 两个按钮自动左对齐，贴近 mac 交通灯右侧
  - Windows 则贴近左缘布局起点

### 3. 裸 icon action 盒模型

- 按钮使用 24px 图标，不再继承通用 `Button` 的字号、圆角和 padding
- 容器使用整条标题栏高度承载，按钮自身只保留 icon action 点击盒
- SVG 统一 `display:block`，避免 inline SVG 基线导致的上下漂移

### 4. 搜索区收敛

`ChatSessionsPane` 顶部搜索区只保留搜索入口，不混入会话操作按钮。

### 5. 全局入口统一

- 聊天页的会话侧栏切换按钮与工作台的 Sidebar 收缩按钮共用同一颗组件
- 统一图标、交互盒模型和 hover 语义
- 避免聊天页和工作台各自维护一套近似但不一致的按钮

### 6. 会话重名可访问性

会话列表中如果同名条目同时出现，可访问名称追加 Agent 后缀，避免屏幕阅读器和自动化测试拿到重复名称。

## 风险控制

- 不修改 `MainLayout` 的聊天路由骨架
- 不修改刷新 / thinking / runtime 现有标题栏控制，只调整左侧聊天带内的会话操作入口
- 不改动聊天消息区与输入区布局
