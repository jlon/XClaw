## 当前落地结果

> 注意：以下条目描述的是当前仓库已落地能力。2026-03-22 已确认默认窗口布局仍需从“默认两栏工作台”纠偏为“默认入口卡片板”，相关界面重做尚未开始提交实现。

- 频道页已具备分段式工作台结构，左栏统一新增入口并支持搜索
- 中栏已按账号维度展示默认账号、绑定状态、启停状态与删除动作
- 右栏已接入基础配置、通用行为、渠道专属高级区、插件源码参数区
- 布尔值字段统一使用开关 UI
- 已证实存在默认值的字段会在编辑器中直接展示默认值
- 新增 `getChannelEditorValues()`，补齐布尔 / 数组 / 数字字段的工作台回填链
- 当前已展示的插件参数字段，已按真实读回能力修正为 `current-xclaw-roundtrip`
- 高级折叠区会基于当前值 / 默认值显示摘要，密码字段只显示“已填写”
- 切换频道时如果右栏有未保存修改，会先弹确认；保存后会重新回读 editor-values
- 左栏选中态、搜索框、右栏基础配置区已去掉固定暖色 hex，改用主题兼容的暖色 / 深色 surface
- `ChannelConfigModal` 里的主卡片、说明区、输入框、密码按钮也已切到主题 token，不再单独保留旧暖色皮肤
- 新增账号保存成功后，页面会刷新账号列表并自动切到刚保存的账号，右栏直接显示该账号的实际配置
- 仓库现在已有可执行的 `pnpm run test:e2e`，并覆盖频道中心的浅色主流程与深色 modal smoke
- 右栏字段可以按可访问名称稳定定位，e2e 不再依赖 placeholder 猜测字段
- 频道页首屏进入时不再默认强制 runtime `probe`，只有用户手动刷新才会主动探测，实际进入速度更稳
- `MainLayout` 与频道页壳层已一起收敛横向留白，宽屏下三栏能更充分使用空间
- `Agents / Skills / Cron / Models / Settings / Channels` 现在都挂在共享 `WorkspacePage` 壳层上，页面间的留白与滚动行为不再各自漂移
- 左栏插件角标已从频道卡片移除，减少窄宽度下的拥挤和错位
- 中栏账号卡片、右栏行为卡片已允许换行，缩放后不再依赖单行硬撑
- 中文主文案已把“绑定对象”“ID:”等技术感表达改成更自然的账号 / Agent 语言
- 右栏内部编辑区与页面主滚动区都已弱化滚动条，Windows 也走单独策略，体验与聊天栏更一致
- 页面里只保留右栏保存按钮作为强主动作，新增 / 文档 / 验证 / 刷新都降级为次级动作，暖色与深色主题下都更协调
- 字段默认值改成内联 badge，说明文案总长度更短，输入框在高缩放下更不容易错位
- `pnpm run test:e2e` 现在会先构建前端，再拉起静态 smoke 服务，端到端链路不再依赖不稳定的 dev server 启服
- 右栏现在允许直接编辑已有账号标识；保存时会真实 rename 账号，并同步迁移默认账号指针、顶层镜像字段与 Agent 绑定
- 左栏每个已配置频道卡片会直接显示“账号数 + 连接状态 + 启停状态”，不再只剩一个容易误解的彩点
- 账号标识输入框、负责 Agent 下拉框和访问控制字段都改成更紧凑的控件节奏，缩放时不容易继续错位
- 已启用的已配置频道卡片现在统一显示绿色状态点，连接状态继续留在文案里，不再和彩点语义打架
- 基础配置区在 `xl` 之前保持单列，WeCom 这类双字段表单不会再过早挤成两列大空白卡片
- 负责 Agent、访问控制和其他枚举字段现在统一使用共享自定义 Select，触发器、展开面板、选中态都跟当前主题一致，不再出现系统原生菜单样式
- 页面内已无原生 `<select>`，右栏“负责 Agent”和访问控制区的箭头、文字、占位和触发器高度已统一
- 中栏头部动作区不再松散换行，添加账号和删除频道会稳定落在同一组里，缩放时也不会在右上角制造大块空白
- 主窗口默认尺寸已从 `1280x800` 调整为 `1400x820`，最小尺寸同步收敛到 `1100x640`，默认打开时频道页右栏不再容易被窗口宽度直接截掉
- 频道页首屏现在已切到入口卡片板；默认窗口点击卡片后进入聚焦编辑态，只有超宽时才进入完整 workbench
- 聚焦编辑态已补齐“返回全部频道”、账号列表、配置编辑器和未保存修改拦截
- 账号列表与配置编辑器已经拆成独立面板，后续超宽三栏可以直接复用，不需要再复制微信 / Agent / 默认账号逻辑
- 首屏入口板已去掉重复的“支持的频道”大标题和说明，默认窗口首屏信息密度更接近 QClaw 的极简目录
- 左栏和账号卡片的状态点现在统一使用柔和呼吸效果：已连接保持低振幅绿色呼吸，未连接改成不刺眼的暖色弱呼吸，`prefers-reduced-motion` 下自动停掉
- 频道页本轮继续从 dashboard pane 收向 split-pane：页头 hero 已收成轻 toolbar，三栏 section 改成统一 pane surface，左栏搜索更像轻筛选器，选中态和 hover 也降回 source-list 语义
- 中栏账号列表和右栏编辑区继续去卡片感：账号项压回列表行 + 次级摘要，右栏 `Basic / Behavior / Advanced` 也退出“卡片套卡片”的网页 settings center 语法
- 入口卡片现在统一展示渠道级说明文案，已配置卡片不再泄露默认账号 ID，而是改为渠道级摘要 + 聚合状态
- 入口板搜索和工作台左栏搜索已拆分成两套状态；从入口板筛选后进入频道，不会再把旧筛选条件带进工作台
- 本轮继续做了一次“桌面化清理”：入口卡片高度和阴影收敛，聚焦编辑态页头去 hero 化，账号区从详情卡片改成资源行，右栏编辑器统一收紧成更轻的 pane 语法
- 已选中频道时，如果 gateway 未就绪，顶部会优先显示运行态不可用提示；只有在入口板首屏才保留通用 `gatewayWarning`，避免账号区继续把“未就绪”误写成“已断开”
- 右栏 `基础配置 / 消息接入规则` 已进一步退回 inspector 语法：可视标题收敛为更短的 `配置 / 接入规则`，说明文案退出首屏，分组头改成单行摘要
- 高级 `接入规则 / 插件设置` 分组现在也进入 compact inspector：默认按容器宽度走两列字段网格，减少长串单列卡片造成的纵向拖沓
- 这一轮把 review 中指出的 dark 断层也闭环了：`desktop-app-shell / body / sidebar / chat-nav / workspace` 已全部切回 theme token，不再残留浅色硬编码
- 右栏编辑器继续从“section 卡 + field 卡 + input 卡”往桌面 inspector 收：compact 字段与基础 `accountId` 现在都退出 filled-card，改成更连续的属性行
- 入口卡片、rail 选中态、聚焦头部图标与账号选中态都去掉了旧的白色 inset highlight 和厚 rgba 阴影，但仍保留必要的层次深度，没有走过度扁平化
