# 应用图标品牌对齐问题记录

## 当前已知问题

1. 原有图标 README 仍描述旧的蓝色爪形方案，和实际品牌方向不一致。
2. 浏览器入口此前没有显式 favicon 引用，导致 Web 入口缺少品牌统一。
3. 共享 renderer logo 在浅色背景下使用青色眼位高光时，小尺寸识别度不够直观。
4. 品牌位此前通过整图滤镜统一染色，会把眼位细节一起抹平。
5. macOS 状态栏模板图如果直接叠黑点，系统模板渲染时会和主体合并，眼位依然不可见。

## 风险

1. 透明主图在 Windows 极小尺寸下可能比带底板图标更依赖轮廓清晰度。
2. macOS 托盘图标必须保持模板图语义，不能直接复用彩色主图。

## 处理结果

1. 共享 `src/assets/logo.svg` 已改为更大的白色眼点，聊天栏与侧栏中的龙虾眼位更容易识别。
2. 品牌位已改为原色显示，不再用整图滤镜把眼位细节染没。
3. macOS 状态栏模板图已改为透明眼洞方案，菜单栏里会显示两个黑色眼位。
