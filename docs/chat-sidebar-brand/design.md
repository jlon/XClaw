# 聊天左栏品牌位

## 目标

在聊天左栏顶部增加合理的 XClaw 品牌展示，让聊天页与工作台侧栏保持一致的品牌语法，同时不挤占标题栏和搜索区。

## 设计约束

- 不把品牌位塞进标题栏，避免和聊天页顶栏控件抢层级
- 品牌位放在聊天左栏内部，并位于搜索框上方
- 复用工作台 `Sidebar` 的品牌语法，不再维护两套近似的 `logo + XClaw`
- 聊天页版本更紧凑，避免头重脚轻

## 实现方案

### 1. 抽取共享品牌组件

新增共享品牌组件：

- 输出 `logo + XClaw` 锁定组合
- 支持 `collapsed` 和 `compact` 两种轻量差异
- 保留现有 `Sidebar` 的字标、渐变和过渡语法

### 2. 工作台侧栏复用

`Sidebar` 不再内联品牌结构，改为直接复用共享品牌组件。

这样后续如果调整品牌样式，只需要改一个地方。

### 3. 聊天页品牌位

在 `ChatSessionsPane` 顶部增加一行紧凑品牌位：

- 位置：搜索框上方
- 风格：与工作台侧栏一致，但更紧凑
- 不添加额外按钮、描述或副标题

## 风险控制

- 不修改标题栏布局
- 不修改聊天左栏底部工作台菜单与设置入口
- 不改变搜索、会话列表和删除逻辑
