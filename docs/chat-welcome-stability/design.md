# 聊天欢迎页稳定性设计

## 背景

启动应用时，聊天欢迎页经常处于 `gateway starting` 等运行态，此时欢迎页会额外渲染一条运行状态文案。新建聊天后的欢迎页通常已经处于 `running`，不会显示这条文案。两者虽然使用同一套欢迎页组件，但因为状态文案是否参与正常文档流不同，导致整块 hero 的垂直居中高度不一致。

## 目标

1. 启动欢迎页和新建聊天欢迎页保持一致的垂直几何高度。
2. 保留运行态提示能力，不隐藏 `starting` / `error` 等状态。
3. 只修欢迎页状态槽位，不改动欢迎页卡片、logo、文案和输入区布局。

## 方案

1. 将欢迎页运行态文案改为固定槽位。
2. 无运行异常时保留同等高度的占位容器，但内容设为不可见，不参与可访问状态播报。
3. 有运行异常时复用同一槽位显示真实状态文案。

## 范围

### 包含

- `src/pages/Chat/index.tsx`
- `src/styles/globals.css`
- `tests/unit/chat-render-stability.test.tsx`

### 不包含

- 欢迎页主视觉改版
- 新建聊天路由逻辑改造
- Gateway 启动策略调整
