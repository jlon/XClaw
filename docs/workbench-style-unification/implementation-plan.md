# 工作台风格统一实施计划

## 目标

在不破坏各页业务主结构的前提下，把 `模型 / 智能体 / 频道 / 技能 / 定时任务` 全部拉回同一套桌面工作台语法：

- `QClaw substrate, XClaw accent`
- `技能` 页作为本地工作台密度参考
- 浏览区 + detail pane 的两层主 surface 合同
- 单页单主任务心智

## 实施原则

### 1. 先改结构合同，再改局部组件

优先级必须是：

1. 页头与工具带
2. 浏览区节奏
3. detail pane 层级
4. 市场/安装等特殊模式

禁止继续跳着改某一张卡片的圆角、颜色或阴影。

### 2. 先删重复，再补图标

如果页面显得乱，第一刀永远先删：

- 重复摘要
- 重复 badge
- 重复事实卡
- 重复 CTA

图标只在删完之后补。

### 3. 保留业务主结构，不搞伪统一

- `频道` 继续是 split-pane
- `智能体` 继续是浏览区 + detail workbench
- `技能` 继续是卡片浏览 + 详情/弹层
- `定时任务` 继续是任务列表 + 编辑

统一的是桌面工作台语法，不是业务骨架模板。

## 分阶段计划

### 阶段 1：统一页头与工具带

- 收紧标题、模式切换、搜索、刷新、主动作的高度与留白
- 去掉大 hero 和说明副标题
- 让工作台顶部先进入同一套 utility grammar

### 阶段 2：统一浏览区

- `模型 / 技能 / 智能体 / 市场 / 频道列表 / 定时任务列表`
- 搜索字段统一成 utility field
- 卡片或列表项统一进入稳定密度
- 选中态、hover、默认态的差异固定下来

### 阶段 3：统一 detail pane

- hero 只保留身份、状态、主动作
- 事实区改成轻摘要，不再堆后台卡片
- 编辑器、绑定区、市场安装区分别回到主任务面

### 阶段 4：跨页真实验收

- 默认窗口大小下审查所有工作台
- 确认没有一页重新长回网页 hero
- 确认没有一页因为“去网页感”而变成发虚白板

## 当前优先级

### 已进入收口阶段

- `智能体`
- `技能`
- `频道`
- `定时任务`

### 仍需继续校准

- `模型`
- `智能体` 的 detail pane 最后一轮质感收口

## 交付标准

只有满足下面 4 条，才算本特性完成：

1. 五个工作台切换时，视觉语言和动线保持一致
2. 任何页面都不再出现后台摘要墙或网页 hero
3. 默认窗口下仍有清晰层级，不发虚、不扁平
4. mac / Windows 都沿用同一套工作台合同，仅保留轻平台差异
