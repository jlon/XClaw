## 当前结论

- 统一方向必须是 `Workbench Header Grammar`
- 不是统一成一张模板皮
- 不允许为了统一而牺牲桌面 split-pane / workbench 的信息效率
- 必须继续遵守 `QClaw substrate, XClaw accent`
- 本轮统一范围已经收窄到“页头 grammar + summary + utility field”，不触碰主体工作区重排
- 实现必须落到共享 primitive，不能用五页复制粘贴近似实现
- 信息压缩优先级高于视觉装饰，轻图标只作为扫描辅助，不作为补偿性装饰层
- 页头已有主创建动作时，空态不得再复制第二颗主按钮
- `定时任务` 新建与编辑流程现在都必须显式指定执行智能体，host / IPC 创建链也会拒绝空 `agentId`
- `Cron` 不能继续使用大 hero + 空状态条 + 松散卡片结构，必须优先收紧信息密度
